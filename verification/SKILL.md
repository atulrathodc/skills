# Web Research

- Search broadly first to discover relevant sources.
- Prefer primary sources and official documentation.
- Fetch the most relevant sources before drawing conclusions.
- Cross-check important claims when multiple authoritative sources exist.
- Distinguish facts from inference.
- Include source references for externally derived claims.
- Do not repeatedly search the same query when the existing evidence is sufficient.
- When documentation exists, prefer documentation over blog posts.
