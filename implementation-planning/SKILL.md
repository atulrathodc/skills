# Implementation Planning

Every plan should answer:

- What changes?
- Why?
- Which files?
- Which symbols?
- What dependencies exist?
- What tests change?
- How will success be verified?

Prefer modifying existing abstractions over introducing parallel implementations.

Plans must be based on inspected repository evidence.
