# API Discovery

Identify:

- routes/endpoints
- controllers/handlers
- request DTOs
- response DTOs
- validation
- authentication/authorization
- service layer
- persistence
- API clients
- frontend consumers
- integration tests

Preserve existing API contracts unless the task explicitly requires a breaking change.
