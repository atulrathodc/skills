# Reproduction Search

Search current, sourced, structured AI knowledge — do NOT rely on memory alone.

- Search for the paper title + 'reproduction' / 'replication' / 'implementation notes' and read issues/blogs.
- Collect the exact hyperparameters, data, and seeds others used, plus pitfalls they hit.
- Report: successful repro notes, discrepancies, and a minimal first-run command.

- Always include URLs and a date; if you cannot verify recency, say so instead of guessing.
