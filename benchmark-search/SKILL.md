# Benchmark Search

Search current, sourced, structured AI knowledge — do NOT rely on memory alone.

- Pick benchmarks that match the task (reasoning/math/code/agent/multimodal); read the official metric definition.
- Find comparable baselines and their exact settings (prompt, few-shot, sampling) — only compare apples to apples.
- Report: benchmark + metric, the reference numbers and settings, and how to run it locally.

- Always include URLs and a date; if you cannot verify recency, say so instead of guessing.
